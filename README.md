# Airbnb Clone Project

This project is a simplified clone of the Airbnb web platform. It is part of a full-stack web development learning journey.

## Project Goals

- Recreate key features of the Airbnb website
- Understand full-stack web application architecture
- Practice using Git for version control and collaboration

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask (backend)
- MySQL (database)

## UI/UX Design Planning.

	* Designs

		- Create intuitive booking flow
		- Maintaining visual consistency
		- Ensure fast loading times
		- Prioritize mobile responsiveness

	## Key Features

		- Property search and filtering
		- Detailed property viewing
		- Securing checkout process 
		- User authentication
